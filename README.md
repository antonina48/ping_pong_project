## Описание проекта
Программа представляет собой классическую двухпользовательскую аркадную игру "Пинг-понг", разработанную на языке Python с использованием графической библиотеки Tkinter. В приложении реализована двумерная анимация движения игрового мяча, физика упругого отскока от границ игрового поля и подвижных ракеток, а также автоматический подсчет набранных очков для каждого игрока.

## Функциональные возможности
### Основной функционал
- Управление левой и правой ракетками в реальном времени.
- Симуляция упругого столкновения мяча с препятствиями (физика отскока).
- Ведение и отображение счета матча на игровом экране.
- Автоматический перезапуск раунда после гола с подачей в сторону победителя.

### Дополнительный функционал
- Постепенное увеличение скорости мяча при каждом успешном отскоке от ракетки для повышения динамики игры.
- Цветовая индикация элементов поля и простая адаптивная верстка под фиксированный размер окна.

## Требования к системе
- **Python:** 3.9 или выше
- **Операционная система:** Windows
- **Библиотеки:** Используются только стандартные встроенные компоненты (`tkinter`, `time`, `math`).

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd ping_pong_project
```

### 2. Активация предустановленного виртуального окружения
*Для Windows:*
```bash
venv\Scripts\activate
```
*Для macOS/Linux:*
```bash
source venv/bin/activate
```

### 3. Запуск программы
```bash
python main.py
```

### 4. Управление в игре
- `W` / `S` — движение левой ракетки (Вверх / Вниз).
- `Стрелка Вверх` / `Стрелка Вниз` — движение правой ракетки (Вверх / Вниз).
- `Space` — поставить игру на паузу / снять с паузы.
- `R` — полный сброс счета и перезапуск матча.



## Структура проекта
```text
ping_pong_project/
├── .gitignore
├── README.md                   # Описание проекта и инструкция
├── requirements.txt            # Зависимости проекта
├── main.py                     # Точка входа в программу
└── src/
    ├── app.py                  # Главный класс приложения (окно, цикл)
    ├── models/
    │   └── animation_model.py  # Математическая модель физики и логики
    └── renderers/
        └── renderer.py         # Модуль графической отрисовки объектов
```

**Назначение основных модулей:**
- `main.py` — Точка входа, которая инициализирует окружение и запускает приложение.
- `app.py` — Класс управления окном Tkinter, обработчик нажатия клавиш и игровой таймер обновления кадров.
- `animation_model.py` — Расчет координат мяча, ракеток, обработка коллизий столкновений и логика начисления очков.
- `renderer.py` — Отрисовка графических примитивов на Tkinter Canvas на основе данных из модели.
